# 🌿 EcoDescarte — Plataforma de Gestão de Coleta Seletiva

## ❓ Problema
A população enfrenta dificuldades para localizar pontos adequados de descarte de resíduos recicláveis e eletrônicos, além de carecer de um canal simples para agendar e acompanhar coletas.

## 🎯 Objetivo
Desenvolver uma aplicação web em React com fluxo simulado de autenticação, rota protegida e funcionalidades de gestão de coletas, mantendo rastreabilidade completa das tarefas no Trello e no GitHub.

## 🚀 Funcionalidades Implementadas
- **Autenticação simulada:**
  - Cadastro de usuário com validação de campos e mensagens condicionais.
  - Login simulado com atualização de estado de sessão e redirecionamento.
  - Recuperação de senha simulada com feedback visual.
  - Área restrita protegida por rota (bloqueio para usuários não autenticados).
  - Logout com limpeza de estado e atualização condicional da navegação.
- **Funcionalidades específicas do projeto (MVP):**
  - Listagem dinâmica de coletas utilizando arrays de objetos e componentes reutilizáveis com `Props`.
  - Cadastro e edição de registros gerenciados com `useState` e eventos de formulário.
  - Pesquisa textual e filtro por categoria na listagem.

## 🛠️ Tecnologias Utilizadas
- React (criado com Vite)
- React Router DOM
- CSS3 / HTML5
- Git & GitHub
- Trello
